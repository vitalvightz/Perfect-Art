# Perfect Art

Landing page for Perfect Art, an events business running club nights and bar takeovers in London.

## Running it

`index.html` is a single self-contained page. Open it in a browser, or serve the folder with any static host (for example GitHub Pages).

## Before launch

- Ticket names, prices, perks and checkout links: the two ticket cards are placeholders. Set `data-checkout-url` on each `.ticket` to send buyers to your ticketing provider.
- Next-night date, name and countdown target (see the countdown script near the bottom of the page).
- Brand colours: all colours are tokens at the top of the `<style>` block.
- Instagram handle and contact email in the footer.
- The mailing list form shows a confirmation but does not store emails yet.
